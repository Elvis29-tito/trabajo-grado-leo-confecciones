# Sistema de Gestión LEO-CONFECCIONES

Este repositorio contiene el sistema de gestión para el taller de confecciones LEO-CONFECCIONES, desarrollado como proyecto de grado.

## Estructura del Proyecto
- `documento/`: Documento de tesis (Word).
- `docs/`: Documentación técnica y diagramas.
- `src/`: Código fuente de la aplicación Flutter.

## Estado del Proyecto
✅ Aplicación funcional con sincronización a Firebase.  
✅ Generación de comprobantes PDF.  
✅ Gestión de clientes, insumos, stock y ventas.

## Tecnologías Utilizadas
- **Flutter** (Frontend)
- **SQLite** (Base de datos local)
- **Firebase Firestore** (Sincronización en la nube)
